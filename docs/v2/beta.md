# The beta page

`beta/` is a small static page served at <https://riksdata.org/beta/>. It shows what the v2 pipeline has so far: the published series as small charts, and the status of every source in the catalogue. The v1 site at the root of riksdata.org is untouched.

It is a stopgap. The planned v2 site is Astro with Observable Plot, built and deployed by GitHub Actions (PLAN.md Phase 2). Until that exists, GitHub Pages serves the repository as it is, so the page and its data have to be committed.

## Rebuilding it

```bash
uv run riksdata update            # refresh the lake
uv run riksdata validate
uv run riksdata check-sources     # optional: refresh the source status board
uv run riksdata export            # writes beta/data/
```

Then commit `beta/data/` and merge to `main`. Pages picks it up within a few minutes.

To look at it locally, run `python3 -m http.server 8765` in the repository root and open <http://127.0.0.1:8765/beta/>.

## Files

| Path | What it is |
|---|---|
| `beta/index.html`, `beta/style.css`, `beta/app.js` | The page. Hand-written, no build step and no dependencies |
| `beta/data/catalog.json` | One entry per published series: metadata, latest value, the value a year earlier, a 20-year sparkline |
| `beta/data/series/<series_id>.json` | The full series: `{meta, entities: {NOR: {period: [...], value: [...]}}}` |
| `beta/data/sources.json` | The latest `check-sources` report: name, section, priority, status. No response content |
| `beta/data/build.json` | When the export ran, counts, and the validation result |

`beta/data/` is generated by `riksdata export`. Don't edit it by hand. It is about 0.9 MB and no file is over 150 KB.

## What is published

Only series with `publish = true` in the lake are exported. A series that becomes unpublished has its file removed by the next export. Today that leaves out five OWID charts whose upstream terms are non-commercial, share-alike or not yet read (see `docs/v2/sources/owid.md`).

The source board shows status only. Samples of the checked responses stay in `lake/`, which is not in git.

## How the page works

- **Tallene.** Series are grouped by topic, then by dataset. Each row shows the latest value for Norway, the change from the same period a year earlier (percentage points for shares, per cent otherwise) and a sparkline of the last 20 years. The change is not coloured, because whether up is good depends on the series.
- **A series.** Clicking a row opens the full history as a line chart with a crosshair and a tooltip that lists every country at that date, a table of the numbers, the source, licence, unit and dates, and a CSV download. The address becomes `#serie=<series_id>`, which can be shared.
- **Other countries** are drawn in grey as context, with Norway in blue. Projections are marked `ESTIMAT`.
- **Kildene.** Every row of `SOURCES.md` with the status from the last `check-sources` run, an icon and a label for each status, filters by status and a search box.
- **Accessibility.** The chart can be read with the arrow keys, every chart has a table, statuses are never shown by colour alone, and the page follows the system's light or dark mode.
- The page has `noindex`, so search engines leave it alone until the real launch.

## Known limits

- Titles of OWID charts with several columns mix Norwegian and English ("Medianalder: Median age - UN WPP").
- Units are shown as published: Norwegian from SSB, English from OWID.
- Licence names are shown as each source writes them ("CC-BY-4.0" from our SSB registry entry, "CC BY 4.0" from OWID).
- There is no per-capita, index or real-terms toggle yet. Those come with the Explorer in Phase 2.
